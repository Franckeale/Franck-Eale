# ChatGPT Creative Commands

A personal collection of creative prompt shortcuts for ChatGPT image generation and image editing.

> These are **prompt aliases / creative command ideas**, not official built-in ChatGPT slash commands. Use them as a quick way to describe the visual transformation you want.

## Commands

### `/8kportrait`
Create a highly detailed, photorealistic portrait with crisp facial detail, natural skin texture, cinematic lighting, shallow depth of field, and an 8K-style finish.

**Example**
```
/8kportrait
Create a professional cinematic portrait while preserving the person's identity and facial features.
```

### `/anime`
Transform the subject into a polished anime-style character while preserving recognizable facial features, pose, hairstyle, and overall composition.

**Example**
```
/anime
Keep the same person and outfit, but render the image as a detailed modern anime illustration.
```

### `/bts`
Create a behind-the-scenes version of a scene, showing the production environment, lighting rigs, cameras, crew elements, or studio setup around the original composition.

**Example**
```
/bts
Turn this image into a cinematic behind-the-scenes film-set photograph.
```

### `/coverstory`
Transform the image into an editorial magazine-cover concept with premium fashion photography, strong composition, and cover-ready styling.

**Example**
```
/coverstory
Create a luxury editorial magazine cover while keeping the person's face unchanged.
```

### `/impossibleangle`
Reimagine the scene from an unusual or physically difficult camera angle, such as an extreme overhead, low-angle, reflection, fisheye, or cinematic perspective.

**Example**
```
/impossibleangle
Show the same subject from a dramatic impossible camera angle while keeping the scene recognizable.
```

### `/movieposter`
Turn the image or concept into a cinematic movie poster with dramatic lighting, strong visual hierarchy, atmospheric effects, and poster composition.

**Example**
```
/movieposter
Create a dramatic cinematic poster using the subject as the main character.
```

### `/worldinside`
Create a surreal “world inside” composition in which a miniature world, landscape, city, galaxy, or symbolic environment appears inside the subject or an object.

**Example**
```
/worldinside
Create a surreal miniature universe inside the silhouette while preserving the original portrait.
```

### `/cyberpunk`
Transform the scene into a futuristic cyberpunk environment with neon architecture, holographic details, rain, technology, and cinematic atmosphere.

**Example**
```
/cyberpunk
Keep the subject recognizable and place them in a futuristic neon cyberpunk city.
```

### `/chibi`
Create a cute chibi version of the subject with a large head, small body, expressive features, and clean illustration styling.

**Example**
```
/chibi
Turn the person into a cute chibi sticker character while preserving the hairstyle and outfit.
```

### `/doubleexposure`
Create a double-exposure composition blending a portrait with another scene, landscape, city, nature, or symbolic imagery.

**Example**
```
/doubleexposure
Blend the portrait with a mountain landscape using an elegant cinematic double-exposure effect.
```

### `/goldenhour`
Re-light the scene with warm golden-hour sunlight, soft shadows, natural highlights, and a cinematic sunset atmosphere.

**Example**
```
/goldenhour
Keep the image composition but change the lighting to warm golden-hour sunlight.
```

## Suggested workflow

1. Upload or describe the image.
2. Type one of the commands above.
3. Add the specific changes you want after the command.
4. Mention anything that must remain unchanged, especially identity, face, clothing, text, or composition.

For example:

```
/movieposter
Keep the original face unchanged. Add dramatic cinematic lighting, subtle smoke,
a dark city background, and the title "THE LAST JOURNEY".
```
